🏥 Smart Hospital Management System

A simple and efficient Smart Hospital Management System developed using C++. This project helps manage essential hospital activities, including patient records, appointments, billing, and patient discharge through a user-friendly, menu-driven console application.

📌 About the Project

The Smart Hospital Management System is a student project developed to demonstrate the practical implementation of C++ programming concepts, object-oriented programming, and file handling.

The system helps organize patient information, maintain records, and simplify basic hospital management tasks. File handling is used to store information so that records can be retained between program executions.

✨ Features

- Patient Management: Add and manage patient information.
- Patient Records: Store and retrieve patient details.
- Search Patients: Find patient records using the available search functionality.
- Appointment Management: Manage appointments if implemented in the current version.
- Billing System: Calculate and maintain patient billing information.
- Payment Management: Record payment details.
- Patient Discharge: Manage the discharge process.
- File Handling: Store records in files for future access.
- Menu-Driven Interface: Simple console interface for easy navigation.

🛠️ Technologies Used

- Programming Language: C++
- Concepts: Object-Oriented Programming (OOP)
- File Handling: C++ file streams ("ifstream", "ofstream", "fstream")
- Input/Output: Standard C++ libraries
- Development Tools: Any compatible C++ compiler or IDE

⚙️ Requirements

Before running the project, ensure that you have:

- A C++ compiler such as GCC or MinGW.
- An IDE or text editor such as Visual Studio Code, Code::Blocks, or Dev-C++.
- Basic knowledge of compiling and running C++ programs.

🚀 Getting Started

1. Clone the Repository

Open your terminal or command prompt and run:

git clone https://github.com/vansh300608/Smart-Hospital-Management-System.git

2. Open the Project Folder

cd Smart-Hospital-Management-System

3. Compile the Program

If your main source file is named "main.cpp", compile it using:

g++ main.cpp -o hospital

Note: If your source file has a different name, replace "main.cpp" with the actual filename. If the project contains multiple source files, compile them together as required.

4. Run the Program

On Windows:

hospital.exe

On Linux or macOS:

./hospital

💻 How It Works

1. Run the compiled program.
2. Select an operation from the displayed menu.
3. Enter the required patient or billing information.
4. View, search, or update records using the available options.
5. Manage payments and patient discharge where supported.
6. Exit the program after completing the required operations.

The exact menu options depend on the current implementation of the source code.
